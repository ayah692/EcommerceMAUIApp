# EcommerceMAUIApp


An elegant, feature-rich .NET MAUI mobile application simulating an e-commerce shopping experience. Built with a clean, responsive UI and dynamic front-end functionality.

## ✨ Features

- 🔍 **Inventory Management**  
  - Add, edit, delete products  
  - Inline quantity input and cart addition  
  - Sorting by Name or Price

- 🛒 **Shopping Cart System**  
  - View items, increase/decrease quantity  
  - Multiple carts (Wishlist support)  
  - Return to inventory or move between carts

- ⚙️ **Tax Configuration**  
  - Adjustable tax rate  
  - Accurate subtotal, tax, and total calculation

- 💅 **UI Design**
  - Background images for sections  
  - Neatly organized buttons and layout  
  - Clear labels, responsive elements


## 🛠️ Technologies Used

- [.NET MAUI](https://learn.microsoft.com/en-us/dotnet/maui/)
- C#
- MVVM Architecture
- XAML for UI design
